关于这个项目

这不仅仅是一个个人博客，更是我作为前端开发者践行工程架构思维与技术热情的试验田。 我目前正在积极寻找前端开发相关的工作机会 (求职中)，随时准备为优秀的团队创造价值。

项目底层基于 Nuxt 3 (Vue 3) 和 TypeScript 全新构建， 使用 Nuxt Content 实现卓越的无头化 Markdown 渲染， 并采用 Tailwind CSS 构建了高内聚、低耦合的原子化组件系统。

从 0 到 1 的组件剥离抽象、SSG/SSR 性能优化、语义化 SEO 标签配置，到极其细腻的丝滑过渡动画，这里的每一行代码都倾注了我对代码规范和极致用户体验的追求。
